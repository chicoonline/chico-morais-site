# Rush Time · A Hora do Rush

A game about the push at the metro door: drag people into the blue boarding areas and keep the door clear for those getting off.

Play: https://ahoradorush.chicomorais.com

Designed by Aline Quarti, Ana Paula Moreira, Chico Morais and Daniele Cruz. Playable version, 2026: Chico Morais. All art is hand-made; the code was written with AI assistance.
